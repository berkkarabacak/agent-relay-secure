AgentRelay
GitHub repository

Claude agents that remember the work.

A local-first control plane for long-running Claude Managed Agents: sticky sessions, versioned memory, spend caps, tool approvals, and a dependency-free client for other agents.

Start locallyGet the Python client
Sticky sessions

Stable agent identities with persistent conversations, interrupts, resets, and event recovery.

Versioned memory

Dedicated Markdown memory stores survive fresh sessions and remain editable by your team.

Controlled autonomy

Tool approval policies, live events, session spend caps, and self-hosted worker support.

Run it with your own credentials

Requires Node.js 24. Run npm install, npm run setup, npm run build, and npm start. Your Claude API key stays in .env or the server environment and never reaches browser code.

GitHub Pages is a product preview, not a public Claude proxy. For family deployment, use a private Node.js host with HTTPS and set AGENT_RELAY_ACCESS_TOKEN. The UI and every agent API then require Basic or Bearer authentication.

Local-first by default. No credentials, session databases, local guides with secrets, or build artifacts are included in this repository.
